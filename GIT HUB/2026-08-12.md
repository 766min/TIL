### - GitHub저장소의 기본 구성 요소파일

- 'README.md' : 프로젝트의 첫인상 파일

  - '사람의 인스타 프로필'

  - 프로젝트를 소개하고  목적 설치방법 사용예시 등의 내용을 작성한다.

  - README파일의 좋은예시는 대단한 기술을 썼다기보단 어떤문제가 생겼고, 문제가 생겼을때 어떻게 원인을 분석하고 해결했는지에대한 내용이 좀더 좋을것같다.

- 'LICENCE' : 소프트웨어의 사용 조건을 정해놓은 파일

  - github에 코드를 공개해서 올려놨다고 누구나 마음대로 쓸 수 있는것이 아니다.
  
  - 대표적인 라이선스
    
    - MIT : 자유롭게 소스 코드가 사용가능하다. (저작권등의 라이선스 표시 조건이있을수있음)

    - Apache 2.0 : 대부분 자유롭게 사용가능하지만 특허 관련 조항이있다.

    - GPL : 수정해서 배포할경우는 그 조건을 따라야하는 강한성격이있다.

    - LGPL : GPL보다 조건을 완화한 라이선스

### - GitHub에서 제공하는 기능

- 'Issues' : 버그발견이나 기능을요청하거나, 할 일 등을 팀원들과 공유,관리 할 수 있는 기능

  - 이슈 제목, 내용, 그 이슈를 담당할 담당자 등을 설정할 수 있다.

  - 이슈에 올려진 작업을 마무리하면 Close를 하여 해결된 작업임을 표시할 수 있다. 

    - Label : 작업 분류 : 버그만 모아서 볼 수 있는 버그 태그, 긴급한 작업만 모아서 볼수있는 태그식으로 분류 할 수있다.

    - Milestone : 목표별로 묶음 : 여러 이슈를 하나의 큰 목표로 묶어서 진행 상황을 관리할 수 있다. 

    - Project Board : 진행 상태 관리 보드 : ISSUE나 작업을 화이트보드처럼 배치해서 진행 사항을 관리할 수 있다. (작업을 진행하면서 해야할일 -> 진행중 -> 완료로 카드를 옮겨서 상황을 공유할수 있다.)

  > 협업에서는 Issue를 단순 메모가 아닌 작업의 단위로 사용해라.
  작업 단위로 분해하고, 담당자를 지정하고, 진행상태를 관리해서, PR로 연결시킨다. PR본문에는 Closes #번호 를 써서 Issue와 PR을 자동으로 이어줘야한다.


- 'Pull Request (PR)' : 다른 브랜치에 merge하기전에 코드 변경사항을 다른사람들과 검토하고 병합을 요청받을수 있는 기능

- 'Actions' : 코드를 테스트하거나 배포하는 등의 작업을 자동화할수있는 기능

- 'Releases' : 프로젝트의 버전별 변경사항과 배포 버전을 관리할수 있는 기능

#### Q1. 다음 코드의 실행 결과로 옳은 것은?

```bash
def introduce_self(name, age):

print(f”이름: {name}, 나이: {age}”)

introduce_self(30, “홍길동”)
```
A: 이름: 30, 나이: ‘홍길동’

ㄴ> 함수를 호출해서 매개변수에 넣은 순서대로 들어갔기때문에 이름에는 30이 출력되고 나이에는 '홍길동'이 출력된것이다.

순서대로 "홍길동", 30 출력하고 싶다면 함수를 호출했을때 매개변수자리에 맞게 넣어야한다. 아니라면 처음 함수를 정의할때 다음과 같이 해줘야한다.!
```python
def introduce_self(age, name="홍길동"):
  print(f"이름 :, {name}, 나이 :, {age}")

  introduce_self(30)
```

#### Q2. 함수 정의 시 매개변수 앞에 별표 하나(*)를 붙여 여러 인수를 전달받으면, 파이썬 인터프리터는 이를 어떤자료구조로 묶어서 관리하나요?

A: 튜플(Tuple)

ㄴ> *표시인 *args는 가변인수로 매개변수를 갯수 상관없이 전달받을 수 있는 인수인데 이 가변인수로 전달된 인수는 튜플로 묶여서 전달된다. 그리고 그렇게 묶인 인수들은 자료구조가 튜플이기때문에 값을 변경할 수 없다.

#### Q5. 다음 코드의 출력 결과로 옳은 것은?
```python
def get_average(*scores):
  if len(scores) == 0:
    return 0

  total = sum(scores)
  avg = total / len(scores)

  return avg 
result = get_average()

print(result)
```
A : 0 

ㄴ> 코드풀이: get_average라는 함수를 만들고 가변인수를 이용해 scores는 여러인자를 받을수있는상태다 일단 실행하지않고 대기시키고 if문을 사용하여 len()은 자료구조안에 들어가는 요소의 개수를 알려주는 함수이다.!! 그래서 len(scores)는 받은 인자의 갯수를 알려주는데 0 일경우 return을 만나 0을 반환하고 함수를 종료한다. 그리고 total이라는 변수를 지정하고 안에는 sum함수를 이용해scores값을 다 더해 저장한다. 또 avg라는 변수를 지정하고 안에는 total/len(scores) 이므로 total 값과 scores에 들어온 인자의 갯수를 나눈값을 넣는다. 그리고 return avg를 만나 avg값을 반환하고 함수는 종료된다. 마지막으로 result = get_average()문은 reulst변수에 get_average함수를 호출햇는데 인자를넣지않았다. 그래서 if문에서 0이실행되어 return 0이 실행됐고 함수가 종료된것이다.total, avg는 실행되지 않은꼴임
print(result)는 앞에서 result가 0으로 지정됨
