### | 퍼셉트론

- 퍼셉트론 하나가 뉴런 하나이다.

- 즉, 입력받아서, 가중치를 곱하고 더하고, 활성화 함수를 통과시켜서 하나의 출력을 내는 최소 단위

배경 | 
- 초기의 인공지능은 매우 단순해서 데이터를 오직 하나의 직선으로만 쪼갤 수 있는 한계가 있었다. 하지만 현실에서의 실제 데이터는 곡선이나 복잡한 모양으로 얽혀있다. 
- 이 한계를 깨고 복잡한 패턴을 가진 정보를 유연하게 이해하기 위해 입력층과 출력층 사이에 '은닉층'을 끼워 넣은 다층 신경망이 탄생한다.

| 핵심 동작 원리

  -> 직선 형태의 분리선만 그릴 수 있어 성능이 낮다.

- 다층 구조 모델 (은닉층 추가) : 첫번째 층이 단순한 선이나 면같은 기초 특징을 감지하면, 은닉층이 이 특징들을 다각도로 연산하고 조합하여 사물의 형태나 질감같은 고차원적인 정보를 유연하게 포착한다.

  - 은닉층에 뉴런이 조금만 추가되도 파라미터(가중치와 편향)가 기하급수적으로 늘어나 표현력이 확장된다.

### | 역전파

- 출력층에서 발생한 오차를 입력층 방향으로 거꾸로 거슬러올라가면서 전달한다.(역방향 추적)

- 미분의 연쇄법칙을 사용하여 각 가중치가 오차에 얼마나 영향을 미쳤는지(기울기)를 계산한다.



### | 옵티마이저

- 역전파가 계산해준 기울기값을 받아서 그 정보를 활용해 가중치를 얼마나 (보폭조절)어느 방향으로 이동시킬지 결정하고 업데이트한다.

| 옵티마이저의 종류

기울기를 가지고 가중치를 어떻게 움직이는지의 방법이 서로 다르다

- SGD : 

  - 기울기가 가리키는 반대 방향으로 가중치를 조금 움직이기

  - 지금 방향만 보는것

- Momentum : 
  
  - 이전 이동 방향을 기억해서 다음 이동에 반영하기

  - 지금방향 + 예전에 가던 방향도 보는것

- RMSprop : 
  
  - 최근 기울기를 더 중요하게 보고, 오래된 기울기의 영향은 조금씩 잊어버리기


- Adam(중요) : 

  - Momentum + RMSprop
  
  - 어느방향으로 가는게 좋은지 + 얼마나 움직일지


| 학습률 : lr - Learning Rate

  - 보폭의 크기 ! 

  - 보통 0.001이나 0.01 같은 작은 소수로 시작해서 모델이 학습되는 것을 보면서 보폭을 좁히거나 늘려준다.

  - `optimizer.step()` : 지금까지 역전파가 계산해준 기울기를 바탕으로 모델의 가중치를 실제로 업데이트해 !


#### | 기울기소실 : 

  - 신경망은 '역전파'라는 방식으로 학습한다.

  - 근데 이 거슬러 올라가는 과정에서, 층을 하나씩 거칠 때마다 활성화함수의 미분값과 가중치 등이 계속 곱해진다.
  
  - 이 값들이 보통 작은 경우가 많아서, 여러층을 거치며 계속 곱해지면 기울기 값이 점점 작아진다.

  - 기울기가 거의 0이 되어서 앞쪽 층의 가중치가 얼마나, 어느 방향으로 수정되어야할에 대한 신호를 거의 받지 못한다.

  - 그래서 앞쪽 층의 학습이 매우 느려지거나 거의 이루어지지 않는 문제가 발생한다.

### | ReLU :

- 입력값이 0보다 크면 그대로 통과시키고, 0보다 작으면 그냥 0으로 만들어버리는 아주 단순한 활성화 함수

| 시그모이드의 한계... : 

- 입력값이 아주 크거나 작으면 그래프 경사(기울기(미분값))가 0에 가까워진다.

- 역전파 중 미분의 연쇄 법칙으로 이 0에 가까운 작은 소수점들이 연속으로 곱해지면서

- 초기 입력층 근처의 은닉층 가중치에는 신호가 0으로 죽어버려 학습이 멈춰버린다.

| 해결방법 : ReLU 도입 - !

- 입력이 음수일 때는 0을 반환해 노이즈를 차단하고

- 양수일때는 입력값을 그대로 통과시켜서 미분 기울기를 무조건 1.0으로 지켜준다.

- 그래서 층이 아무리 깊어져도 기울기가 감쇄하지 않고 온전히 살아서 전달된다.


### | 원핫 인코딩과 임베딩

- 원핫 인코딩 : 하나만 1이고 나머지는 0으로 채워 단어간의 독립성만 지키는 방식

- 단어 임베딩 : 

  - 텅빈 0을 다 버리고, 설정한 저차원 공간안에서 실수값으로 가득 채운 밀집 백터로 압축한다.

  - 역전파를 통한 가중치 학습으로 문맥이 비슷한 단어들을 가중치 공간 안에서 서로 기하학적 좌표가 가깝게 뭉치도록 한다.

| 희소 행렬(Sparse Matrix) : 대부분의 값이 0인 행렬

- 예를 들어 단어 5개가 있는데 고양이를 원-핫으로 표현하면 -> [1, 0, 0, 0, 0] 이렇게 1은 하나고 0이 4개다.

- 이런 데이터를 희소하다(Sparse)라고 한다.

- 즉, 희소 행렬은 값 대부분이 0인 데이터 표현 방식이다.


| 단어 임베딩 : 원-핫의 문제를 해결하기 위해 단어를 의미 있는 숫자 벡터로 바꾸는 방법이다.

- 원핫은 고양이 -> [1, 0, 0, 0, 0]으로 표현
- 임베딩은 고양이 -> [0.2, 0.8, -0.1] 이렇게 훨씬 작은 차원의 숫자 벡터로 표현한다.
  - 그리고 이 숫자들은 단순한 0/1이 아니라 학습을 통해 단어의 특징이나 관계를 담게된다.
    - 예를 들어 고양이 -> [0.2, 0.8, -0.1] , 강아지 -> [0.3, 0.7, -0.2]처럼 비슷한 단어가 비슷한 벡터를 가질 수 있다.


| 임베딩 가중치 행렬(Embedding Weight Matrix) : 임베딩의 실제 숫자표

- 예를들어 

고양이  → [0.2, 0.8, 0.1]
강아지  → [0.3, 0.7, 0.2]
토끼    → [0.1, 0.4, 0.9]
자동차  → [0.9, 0.1, 0.2] 

- 이거를 행렬 형태로 쓰면

[0.2  0.8  0.1]
[0.3  0.7  0.2]
[0.1  0.4  0.9]
[0.9  0.1  0.2] 가 된다.


| 임베딩 학습 메커니즘 : 임베딩 숫자들을 처음부터 정답으로 알고 있는게 아니라, 학습하면서 스스로 조정한다.

- 예를 들어 처음에는

고양이  → [0.2, 0.8, 0.1]
강아지  → [0.8, 0.2, -0.5]

- 이렇게 의미 없는 숫자가 들어있을 수 있는데 모델이 문장을 계속 학습하면서 '고양이와 강아지는 비슷한 상황에서 자주 나오네'같은 패턴을 학습한다. 
- 그러면 역전파 + 옵티마이저를 통해 임베딩 가중치도 조금씩 수정된다.

| 비선형성 : 직선으로만 표현할 수 없는 복잡환 관계를 표현할 수 있게 만드는 것

- 신경망도 기본 계산은 선형이지만 여러 층을 쌓아도 중간에 비선형성이 하나도 없으면 결국 하나의 선형 계산과 똑같은 효과 -> 즉, 층을 여러개 쌓았지만 별로 복잡해지지않는다

- 활성화 함수를 통해 비선형성을 만든다.
  - ReLU는 -3을 받으면 0, 2를 받으면 2 이렇게 입력을 그냥 그대로 통과시키는 선형 계산만 있는게 아니라 중간에서 값을 꺾어버린다. 그래서 이런 함수는 비형성을 만든다.
  - 시그모이드는 입력받은게 큰 양수면 1에 가까워지고 0이면 0.5 큰 음수이면 0에 가까워진다. 그래서 그래프가 직선이아닌 S자 형태다. 이것도 비선형석이다.


### | 드롭아웃 : 과적합을 줄이기 위한 방법
- 학습할 때 신경망의 일부 뉴런을 랜덤하게 잠깐 꺼버린다.
- 그러면 모델이 특정 뉴런 몇 개에만 너무 의존해서 외우는 것을 막을 수 있다.
- Dropout(0.2) -> 학습할 때 뉴런으 ㅣ약 20%를 랜덤하게 끈다.

- Dropout은 학습중에만 적용되고, 검증이나 테스트, 실제 예측에서는 적용되지 않는다.

### | 조기종료 : 모델이 더 학습해도 좋아지지 않을 때 학습을 중간에 멈추는 방법

- 훈련 데이터 성능 : 훈련 데이트 성능이 계속 좋아진다해도 어느 순간부터는 모델이 훈련 데이터를 너무 외워버린다.
- 검증 데이터 성능 : 더 이상 좋아지지 않거나 오히려 나빠질수있다. ( 이게 과적합 )

- 그래서 검증 손실같은걸 계속 보다가 로스가 더 안낮춰지면 이제 더 학습하지말자고 멈춘다.

### | 미니 배치 : 한 번에 전체 데이터를 다 사용하지 않고, 데이터를 작은 묶음으로 나눠서 학습한다.


### | 텐서와 자동 미분

#### - 텐서(Tensor) : 숫자를 담는 다차원 배열 그릇

- 딥러닝에서 다루는 모든 데이터(입력값, 가중치, 출력값)를 담아두는 그릇이다.

- 차원(축이 몇개냐)에 따라 부르는 이름이 다르다.

  - 스칼라(0차원) : 숫자 하나 -> 예) 5
  - 벡터(1차원) : 숫자들이 한 줄로 나열된 것 -> 예) [1, 2, 3]
  - 행렬(2차원) : 숫자가 가로세로로 나열된 표 -> 예) [[1,2],[3,4]]
  - 텐서(3차원 이상) : 행렬을 여러 겹 쌓아놓은 것 -> 예) 컬러 사진 여러장(장수, 가로, 세로, 색상)을 한번에 묶은 데이터

-> 즉 텐서는 스칼라, 벡터, 행렬을 전부 포함하는 더 큰 개념이고, PyTorch나 TensorFlow같은 딥러닝 프레임워크는 모든 데이터를 이 텐서라는 형태로 통일해서 계산한다.

#### - 자동 미분(Autograd) : 미분을 사람 대신 계산해주는 기능

- 역전파를 하려면 각 가중치에 대해 손실 함수를 미분해야 하는데, 층이 깊어질수록 이걸 사람이 손으로 계산하기는 너무 복잡해진다.

- 그래서 프레임워크가 계산 과정을 전부 기억해뒀다가, 명령어 한 번으로 필요한 모든 기울기를 자동으로 계산해주는 기능이 자동 미분이다.

```python
import torch

x = torch.tensor(2.0, requires_grad=True)
y = x ** 2

y.backward()  # y를 x에 대해 미분해라

print(x.grad)  # 4.0  (y=x^2의 미분은 2x, x=2일때 4)
```
- `requires_grad=True` : 이 텐서에 대한 계산 과정을 기록해서 나중에 미분할 수 있게 준비해라

- `backward()` : 지금까지 기록된 계산 과정을 거꾸로 따라가면서 미분(기울기)을 계산해라

- `x.grad` : 계산된 기울기 값이 저장되는 곳

-> 사람은 계산식(모델 구조)만 짜놓으면, 그 계산식을 미분하는 귀찮은 작업은 프레임워크가 알아서 해주는 것이 자동 미분이다.

### | 순환 신경망 RNN 

- 순서가 있는 데이터를 처리하기위해 이전 정보(은닉 상태)를 기억하면서 다음 입력을 처리하는 신경망

| 장기 의존성 문제 :

  - 멀리 갈수록 기억이 희미해지는 장기 의존성 문제가 있다.

### | 장단기 메모리 LSTM

- 순환 신경망(RNN)이 문장이 길어지면 앞쪽 정보를 까먹어버리는 장기 의존성 문제를 해결하기 위해 나온 개선된 구조

- RNN은 은닉상태 하나에 모든 정보를 매번 새로 짓이겨서 담다보니 멀리 있는 정보일수록 점점 희미해졌는데,

- LSTM은 은닉상태 말고도 셀 상태(Cell State)라는 별도의 기억 통로를 하나 더 만들어서, 중요한 정보는 오래 남기고 필요없는 정보는 걸러내도록 설계했다.

- 이때 뭘 남기고 뭘 버릴지를 결정하는 장치가 게이트(문)인데, 자세한 계산 과정은 9월 1일 정리에 이어서 담았다.

### | 과소적합과 과적합

#### - 과소적합(Underfitting) : 너무 대충 공부해서 훈련조차 못 맞추는 상태

- 모델이 너무 단순하거나 학습을 너무 조금 해서, 훈련 데이터의 패턴조차 제대로 못 찾아낸 상태

- 훈련 데이터에서도 정확도가 낮고, 검증/테스트 데이터에서도 정확도가 낮다. (둘 다 성능이 안좋음)

- 원인 : 모델이 너무 단순함(층이나 뉴런이 적음), 학습을 너무 일찍 멈춤, 특성(feature)이 부족함

#### - 과적합(Overfitting) : 너무 달달 외워서 실전에서 못써먹는 상태

- 모델이 훈련 데이터의 진짜 규칙뿐만 아니라 노이즈나 우연한 패턴까지 전부 외워버려서, 훈련 데이터에서는 성능이 매우 좋지만 새로운(검증/테스트) 데이터에서는 성능이 뚝 떨어지는 상태

- 훈련 데이터 정확도는 계속 오르는데, 검증 데이터 정확도는 어느 순간부터 정체되거나 오히려 떨어진다.

```
손실(Loss)
  |                              ／ 검증 손실 (다시 올라감 = 과적합 시작)
  |                        ／￣
  |                  ／
  |            ／
  |______／
  |￣￣￣￣￣￣￣￣￣￣￣￣￣￣ 훈련 손실 (계속 내려감)
  +---------------------------------> 학습 진행(epoch)
```

- 훈련 손실은 계속 낮아지는데 검증 손실이 다시 올라가기 시작하는 그 지점을 과적합의 시작으로 본다.

- 해결방법 : 드롭아웃, 조기종료, 규제(릿지/라쏘), 데이터 양 늘리기 등

-> 과소적합은 '공부를 덜 해서 문제', 과적합은 '문제집만 달달 외워서 처음 보는 문제에 약해지는 것'이라고 비유할 수 있다.

### | 은닉 상태

- 은닉 상태(Hidden State, h) : RNN이나 LSTM이 지금까지 입력받은 내용을 압축해서 담아두는 요약 메모장같은 벡터

- 매 타임스텝(단어 하나가 들어올 때)마다, '이전까지의 요약 메모(이전 은닉상태)'와 '지금 새로 들어온 입력'을 합쳐서 '새로운 요약 메모(새로운 은닉상태)'로 업데이트한다.

- 예를 들어 '나는 학교에 간다'라는 문장을 순서대로 읽는다면

  - '나는'을 읽고 -> h1 (지금까지 읽은건 '나는' 뿐이라는 요약)
  - '학교에'를 읽고 -> h2 (지금까지 읽은건 '나는 학교에'라는 요약)
  - '간다'를 읽고 -> h3 (지금까지 읽은건 '나는 학교에 간다' 전체라는 요약)

- 이렇게 매순간 갱신되는 이 요약 벡터가 은닉상태이며, 마지막 은닉상태(h3)는 문장 전체의 의미를 담고있다고 보고 컨텍스트 벡터로 쓰이기도 한다.

### | tanh

- 하이퍼볼릭 탄젠트(tanh) : 입력값을 -1 ~ 1 사이의 값으로 압축해주는 활성화 함수

| 공식 :

$$tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$$

- 시그모이드와 생김새(S자 곡선)는 비슷하지만 출력 범위가 다르다.

  - 시그모이드 : 0 ~ 1 사이로 압축 (전부 양수)
  - tanh : -1 ~ 1 사이로 압축 (음수도 표현 가능, 0을 중심으로 대칭)

- RNN/LSTM에서 tanh를 자주 쓰는 이유 : 

  - 값이 항상 -1~1 사이로 제한되기 때문에, 같은 가중치가 매 타임스텝마다 반복해서 곱해져도 값이 무한히 커지는 폭발현상을 막아준다.

  - 0을 중심으로 대칭이라 출력값이 양수/음수 방향을 골고루 표현할 수 있어서, 정보를 더하거나 빼는(강조하거나 지우는) 표현에 유리하다.

### | 기울기 폭발

- 기울기 소실(Vanishing Gradient)의 반대 현상으로, 역전파 과정에서 기울기가 점점 작아지는게 아니라 오히려 점점 커져서 발산해버리는 문제

- RNN처럼 같은 가중치를 매 타임스텝마다 반복해서 곱하는 구조에서, 그 가중치 값이 1보다 크면 곱해질수록 값이 기하급수적으로 커진다.

  - 예 : 1.5를 10번 곱하면 -> 1.5^10 ≈ 57.7 이렇게 순식간에 값이 폭발적으로 커진다.

- 이렇게 기울기가 너무 커지면, 가중치가 한 번에 너무 많이 업데이트 되어버려서 학습이 널뛰기하듯 불안정해지거나 계산 자체가 무한대(NaN)로 깨져버릴 수 있다.

| 해결방법 : 그래디언트 클리핑(Gradient Clipping)

  - 기울기값이 어떤 최대 한계치를 넘으면, 그 이상은 못 넘게 강제로 잘라내는 방법이다.

  - 예를 들어 한계치를 5로 정해놨는데 계산된 기울기가 20이 나왔다면, 방향은 유지한 채 크기만 5로 깎아서 사용한다.

### | 컨텍스트 벡터

- 컨텍스트 벡터(Context Vector) : 인코더가 입력 문장 전체를 다 읽고 나서 마지막으로 남긴 요약 벡터

- 인코더가 문장을 한 단어씩 순서대로 읽으면서 은닉상태를 계속 갱신하다가, 마지막 단어까지 다 읽었을 때 남은 최종 은닉상태(LSTM이라면 은닉상태+셀상태)가 바로 컨텍스트 벡터가 된다.

- 이 컨텍스트 벡터 하나가 디코더에게 '자, 원문 내용은 이게 다야'라고 넘겨주는 유일한 정보 통로이며, 디코더는 이 벡터를 출발점(초기 은닉상태)으로 삼아 출력을 만들어나간다.

- 다만 문장이 아무리 길어져도 이 벡터의 크기는 고정되어 있어서(예: 256차원), 정보를 억지로 눌러담다가 손실이 생기는 병목현상의 원인이 되기도 한다. (자세한 내용은 9월 1일 정리 참고)
