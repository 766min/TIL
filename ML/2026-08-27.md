### - 선형회귀(Linear Regression) 
- 선형 회귀는 수많은 데이터 점들 사이를 지나가는 '가장 잘 맞는 직선(또는 평면) 단 하나'를 그리는 과정이다.

- 

[ 선형회귀의 기본 방정식 ]

`y=wx+b`

- y : 모델이 학습하여 낸 예측값이다.

- x : 예측에 힌트가 되는 데이터인 입력값(특성). 모델에게 학습시키기위해 주는 문제다.

- w : 가중치/기울기 : x가 커질때마다 y가 평균적으로 얼마나 오르는지를 나타내는 가중치/기울기이다. -> 그래프에서는 선이 얼마나 가파르게 뻗어올라갈지(경사)를 정한다.

- b : 편향/기본값 : 특성과 상관없이, 예측값이 무조건 기본적으로 존재해야 하는 최소한의 기본값.(결과가 한쪽으로 쏠리지 않도록 든든하게 받쳐주는 기준점) 이 값에 따라 직선이 위아래로 움직인다. -> 그래프에서는 기울기의 경사는 그대로 둔채 통째로 위아래로 움직이는 역할이다. b값이 크면 선이 위로 뜨고 작으면 아래로 뜬다.

  - 이 가중치와 절편값을 어떻게 구하냐 -> 맨처음에는 아무숫자나 무작위로 일단 던져서 시작한다. 그럼 당연히 첫 예측은 엄청난 엉터린데 이때 발생하는 전체 오차 점수를 손실함수를 통해 체점한다.(MSE, MAE)
  - 최적의 길을 찾아가는 길이 바로 경사하강법
    - 지금의 가중치와 절편값으로 예측했을때 오차점수가 얼마인지 확인
    - 현재 위치에서 오차 골짜기의 경사가 어느 방향으로 얼마나 가파른지 미분(기울기 계산)으로 측정한다.
    - 미분해서 나온 경사의 반대방향으로 학습률(보폭)만큼 가중치(w)와 편향(b)을 조금씩 수정한다.
    - 이 과정을 수백번 수천번 반복해서 오차가 가장 적은 골짜기 바닥에 도달하게 되고 그때 멈춰 선 지점의 숫자가 바로 가장 완벽한 가중치와 절편값이 된다.
    - 근데 이 목적지를 지나치는게 오버슈팅이다.(학습률을 너무 크게 잡았을때..)

#### - 오차 Error 
  - y - y(헷) -> 정답값 - 예측값

### - 손실 함수 Loss Function
  - 모든 개별 데이터에서 생긴 오차들을 하나로 묶어 종합 점수를 메기는 공식

#### | MSE : 평균 제곱 오차
- 오차들을 전부 제곱한뒤 평균을 낸다. 오차를 제곱하기 때문에 예측이 조금만 튀어도 벌점이 껑충 뛰어버린다.
  - 실제값과 예측값 사이에 오차가 10만원 벌어진 매물데이터가 있을때 이 오차를 제곱하여 무려 벌점 100점이라는 엄청 큰 패널티를 준다.

#### | MAE : 평균 절대 오차
- 오차에 절대값을 씌워 부호를 떼고 정직하게 평균을 낸다.
  - 실제값과 예측값 사이에 오차가 10만원 벌어진 매물데이터가 있을때 정직하게 그냥 벌점 10점을 준다.


### - 경사하강법 : 눈 감고 하산하기

- 왜 필요한가 : 수많은 방 평수와 가격 데이터를 받았을때, 모델이 어떤 원리로 최적의 기울기(y)와 기본값(b)을 찾을수있을까 -> 무작위로 찍어 맞추는 대신, 가장 빠르게 손실을 들어주는 정답의 방향을 더듬거리며 찾아가기위해 필요한 길찾기 알고리즘이다.


- 핵심 동작 원리 : 오차가 큰 상태에서 오차가 0에 가까운 곳을 찾아 내려가야할 때 땅의 경사도를 알아내기 위해 미분을 사용한다.
  - 기울기가 음수일때 (왼쪽높은곳에서 내리막길을 걷고있구나) 가중치(w)를 더 오른쪽(양의 방향)으로 되돌린다.
  - 기울기가 양수일때 (정답을 지나쳐서 오르막기로 다시 올라왔네) 가중치(w)를 왼쪽(음의 방향)으로 되돌린다.
  - 기울기가 0일때 (여기가 바로 오차가 가장 적은명당이구나) 학습을 종료한다. 하지만 실제로 기울기가 완벽하게 0이긴 어렵다
    - 그럼 0이 아닌데 언제 학습을 끝내냐? -> 모델이 학습하다가 완벽한0을 찾다가 영원히 멈추지못할수잇다. 그래서 타협점을 정해둔다. 기울기 절대값이 어느정도 더이상 오차가 의미잇게 줄어들지않을만큼 바닥에 충분히 닿앗다라고 판단되면 멈추게하는 임계값 또는 종료 조건을 부여한다.

#### - 학습률 Learning Rate : 보폭 조절 다이얼 

- 왜 필요한가 : 미분을 통해 어느 방향으로 내려가야 하는지는 알아냈지만 그 한걸음에 얼마나 멀리 내디딜건지의 보폭의 크기를 정해주지 않으면 목적지에 영영 도달하지 못하거나 너머갈수있다. 이 걸음의 단위를 정해주는 하이퍼파라미터가 학습률이다.

- 핵심 동작 원리 :
  - 보폭이 너무 큰 경우 - 학습률(LearningRate)설정값이 너무 클때(오버슈팅) : 이리저리 건너뛰다가 튕겨나간다. 학습 붕괴
  - 보폭이 너무 작은 경우 - 학습률(LearningRate)설정값이 너무 작을때(언더슈팅) : 너무 오래 걸리고 오차가 가장 적어지는 최저점을 찾다가 학습이 멈춰버릴수도있다. 

#### - Train-Test-Split : 모델의 학습 설계도

- 왜 필요한가 : 모델에게 우리가 수집한 데이터 전부를 주고 연습시키면 원리를 배우는게아닌 문제와 정답을 통째로 외워버리는 과적합(Overfitting)현상이 나타난다. 그래서 실제로 검증하기위해 문제를 미리 쪼개놓기 위해 이 설계가 필요하다.

- 핵심 동작 원리 : 

  - 훈련 세트(Train Set - 60%) : 모델에게 훈련시킨 문제와 답을 주고 원리를 익히고 공식의 w와 b를 직접 조정해 학습시킨다.

  - 검증 세트(Validation Set - 20%) : 학습시키는 중간에 학습률같은 조종들이 잘 세팅되어있는지 자가 점검하는 모의고사같은것이다.

  - 테스트 세트(Test Set - 20%) : 모델에게 한번도 보여주지 않은 문제를 보여주는 수능 시험이다.

  #### - 디테일 스케일링 

  - 왜 필요한가 : 어떤특성은 단위가 엄청크고 어떤 특성은 숫자가 아주 작을 수있다. 이렇게 숫자의 체급이 완전 다르면 오버슈팅참사가 생기기 쉽기때문에 이 숫자의 체급을 맞춰줄 필요가 있다.

  - 핵심 동작 원리 : 

    - MinMaxScaler(최소-최대 스케일러) : 가장 작은 값을 0, 가장 큰 값을 1로 맞춰서 모든 데이터의 숫자를 0과 1사이의 비율로 맞춰 들어오게 압축한다.

    - StandardScaler(표준 스케일러) : 데이터의 평균을 0, 흩어진 표준적인거리(표준편차)를 1로 통일한다. 평균에 비해 내위치가 상대적으로 얼마나 높은지를 표준점수(Z-score)로 가공하는 만능 조절기다.
