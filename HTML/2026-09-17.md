### | Flexbox 고급 — 자식 요소의 크기를 조절하는 속성들 |

- 09-16 노트에서 `flex-direction`, `justify-content`, `align-items`까지 다뤘는데, 오늘은 **자식(flex item) 요소 각각의 크기 조절**을 담당하는 속성들을 정리한다.

| 속성 | 적용 대상 | 역할 |
| --- | --- | --- |
| `flex-grow` | 자식 요소 | 부모 안에 **남는 공간**이 있을 때, 그 공간을 자식들이 나눠 갖는 비율 |
| `flex-shrink` | 자식 요소 | 부모 공간이 **부족**할 때, 자식들이 줄어드는 비율(가중치) |
| `flex-basis` | 자식 요소 | 자식 요소의 기본 크기 (기본값 `auto`) |
| `flex-wrap` | 부모 요소 | 자식들이 한 줄에 다 안 들어갈 때 줄바꿈 여부 |

```css
.item {
  flex-grow: 1;    /* 남는 공간을 다른 flex-grow 값들과 비율대로 나눠 가짐 */
  flex-shrink: 0;   /* 공간이 부족해도 이 요소는 줄어들지 않음 (가장 많이 쓰는 값) */
  flex-basis: auto;
}

.container {
  display: flex;
  flex-wrap: wrap;   /* 한 줄에 다 안 들어가면 다음 줄로 넘김 */
  /* nowrap(기본값) : 무조건 한 줄에 욱여넣음 (내용이 찌그러질 수 있음) */
}
```

- **`flex-shrink: 0`을 실무에서 제일 많이 쓰는 이유** : 로고나 아이콘처럼 "절대 찌그러지면 안 되는" 요소에 `flex-shrink: 0`을 줘서, 부모 공간이 부족해져도 그 요소만은 원래 크기를 지키게 만드는 용도로 자주 쓴다.

### | CSS Grid — 2차원(가로+세로) 격자 레이아웃 |

- Flexbox가 "한 방향(가로 또는 세로)"으로 줄 세우는 도구였다면, **Grid는 가로·세로를 동시에 다루는 격자(표) 형태의 레이아웃**을 만드는 도구다.

```css
.grid-container {
  display: grid;
  grid-template-columns: 150px 150px 300px;  /* 열 3개, 각각 너비 지정 */
  grid-template-rows: 100px 100px;           /* 행 2개 */
  gap: 20px 10px;                            /* 행 간격 20px, 열 간격 10px */
}
```

##### | 열/행 크기 지정 |

| 문법 | 의미 |
| --- | --- |
| `grid-template-columns: 150px 150px 300px;` | 고정 크기로 열 3개 생성 |
| `grid-template-columns: 150px 1fr 2fr;` | 첫 열은 150px 고정, 나머지 공간을 1:2 비율로 두 번째·세 번째 열이 나눠 가짐 (`fr` = 남은 공간에 대한 비율) |
| `grid-template-columns: repeat(3, 100px);` | 100px짜리 열을 3개 반복 생성 (같은 크기를 여러 개 만들 때 축약) |

##### | 간격(`gap`) |

- `row-gap` : 행(가로줄)끼리의 세로 간격
- `column-gap` : 열(세로줄)끼리의 가로 간격
- `gap: 20px 10px;` → 앞 값이 `row-gap`(20px), 뒤 값이 `column-gap`(10px)
- `gap: 30px;` → 값 하나만 쓰면 행·열 간격 모두 30px로 동일하게 적용

##### | 칸을 여러 개 차지하게 만들기 |

```css
.box-a {
  grid-column: 1 / 3;   /* 1번 선~3번 선까지, 즉 열 2칸을 차지 */
  /* 또는 */
  grid-column: span 2;  /* 지금 위치부터 열 2칸 차지 (같은 결과) */
}
.box-b {
  grid-row: 1 / 3;       /* 행 2칸 차지 */
}
```

##### | `place-items` — Grid 안에서 가운데 정렬 |

- `stretch`(기본값) / `start`(왼쪽 위) / `end`(오른쪽 아래) / `center`(정가운데)

```css
.grid-container { place-items: center; }
```

- 09-16 노트에서 다뤘던 "가운데 정렬하는 여러 방법" 중, Grid를 쓰면 이 한 줄로 자식 요소를 정중앙에 배치할 수 있다.

### | `overflow` — 박스보다 콘텐츠가 넘칠 때 |

| 값 | 동작 |
| --- | --- |
| `visible` (기본값) | 넘치는 내용이 박스 밖으로 그냥 다 보임 (잘리지 않음) |
| `hidden` | 박스 영역을 벗어나는 내용은 잘려서 안 보임 |
| `scroll` | 넘치는 내용을 스크롤바로 볼 수 있게 함. **내용이 안 넘쳐도 스크롤바가 항상 보임** |
| `auto` | 넘칠 때만 스크롤바가 생기고, 안 넘치면 스크롤바 자체가 안 보임 |

- `overflow-x`, `overflow-y`로 가로/세로 방향을 따로 지정할 수도 있다.

- **`scroll`과 `auto`의 차이가 헷갈리기 쉬운 포인트** : `scroll`은 내용이 넘치든 안 넘치든 무조건 스크롤바 자리를 차지하고, `auto`는 필요할 때만 나타난다. 그래서 실무에서는 대부분 `auto`를 쓴다.

### | `border` — 테두리 |

| 속성 | 설명 |
| --- | --- |
| `border-width` | 테두리 두께 |
| `border-style` | 선 모양 — `none`(기본값), `solid`(실선), `dashed`(파선), `dotted`(점선), `double`(이중선) |
| `border-color` | 테두리 색상 |
| `border-radius` | 모서리를 둥글게 (반지름 값, `%`로도 지정 가능) |

```css
/* 단축 표기 : 두께 스타일 색상 순서 */
.box { border: 2px solid red; }

/* 특정 방향만 없애기 */
.tab { border-left: 0; border-right: 0; }

/* 모서리 둥글게 */
.card { border-radius: 12px; }
```

### | `background` 세부 옵션 |

| 속성 | 값 | 설명 |
| --- | --- | --- |
| `background-repeat` | `repeat`(기본, 가로·세로 반복) / `repeat-x` / `repeat-y` / `no-repeat` | 배경 이미지 반복 방식 |
| `background-position` | `100px 50px` (왼쪽에서 100px, 위에서 50px) 또는 `left top`, `center` 등 키워드 | 배경 이미지 위치 |
| `background-size` | `200px 100px`(가로 200, 세로 100) / `100%`(꽉 채움) / `cover`(비율 유지하며 영역 꽉 채움, 잘릴 수 있음) / `contain`(비율 유지하며 전체가 다 보이게) | 배경 이미지 크기 |
| `background-attachment` | `fixed`(스크롤해도 배경 고정) / `scroll`(콘텐츠와 같이 스크롤) / `local`(요소 자체 스크롤과 함께 움직임, 실무에서 가장 많이 씀) | 스크롤 시 배경 이미지 동작 |

```css
/* 단축 표기 : 색상, 이미지, 반복, 고정, 위치, 사이즈 순서로 조합 */
.hero {
  background: #000 url('bg.jpg') no-repeat fixed center / cover;
}
```

- 단축 표기를 쓸 때, `색상`과 `이미지` 중 **적어도 하나는 반드시 값을 정의**해야 하고 (둘 다 생략은 불가능), 나머지 속성은 안 쓰면 각자의 기본값으로 처리된다.

### | 폰트 관련 속성 — 자간·행간·줄바꿈까지 |

| 속성 | 설명 |
| --- | --- |
| `letter-spacing` | 글자와 글자 사이 간격(자간) |
| `word-spacing` | 단어와 단어 사이 간격 |
| `word-break` | 줄바꿈 처리 방식 — `normal` / `break-all`(단어 중간에서도 강제로 줄바꿈) |
| `line-height` | 행간. 기본값(`normal`)은 대략 1.2(=120%) 정도이고, 보통 1.5 정도로 늘려서 씀 |

- **`line-height: 1.2`가 뜻하는 것** : 글자 높이를 1이라고 하면, 나머지 0.2(20%)만큼의 여백이 위아래로 나눠져서(위 10% + 아래 10%) 줄 사이에 배분된다고 이해하면 된다.

- `text-decoration` : `underline`(밑줄) / `line-through`(취소선) / `none`(장식 없음 — `<a>` 태그 기본 밑줄을 없앨 때 자주 씀)

- `font-style` : `normal`(기본) / `italic`(전용 이탤릭체) / `oblique`(단순히 기울인 것, 각도 지정 가능 — `oblique 15deg;`)

- `font-family` 문법 : `font-family: 폰트명, 대체폰트1, 대체폰트2;` 형태로 쉼표로 나열. **폰트명에 공백이 있으면 따옴표로 감싸야 한다.**
  ```css
  font-family: 'Malgun Gothic', 'AppleGothic', sans-serif;
  /* 순서대로 윈도우 기본체 → 맥 기본체 → 그마저도 없으면 시스템 고딕 계열 */
  ```

### | `position` 복습 — `z-index` |

- `static`(기본값, 요소가 원래 흐름대로 배치) / `relative`(자기 원래 자리 기준 이동) / `absolute`(문서 전체 또는 `relative`/`absolute`/`fixed`가 걸린 가장 가까운 부모 기준) / `fixed`(화면(viewport) 기준 고정)

- **`z-index`** : `position`이 `static`이 아닌 요소들끼리 화면에서 **겹쳤을 때, 어느 게 위로 올라올지**를 숫자로 정하는 속성. 숫자가 클수록 더 위쪽(앞쪽) 레이어에 쌓인다.

### | 미디어 쿼리(`@media`)란 |

- **미디어 쿼리** : 접속한 기기의 특성(화면 타입, 가로 너비 등)을 브라우저가 감지해서, 지정된 조건에 맞을 때만 특정 CSS 스타일을 적용하는 기술.

```css
@media 미디어타입 and (미디어특성) {
  /* 조건이 참(True)일 때만 실행할 CSS */
}

/* 예시: 화면이고 가로폭이 768px 이상일 때만 배경색 변경 */
@media screen and (min-width: 768px) {
  body { background-color: lightgreen; }
}
```

##### | 미디어 타입(Media Type) |

| 타입 | 설명 |
| --- | --- |
| `all` | 모든 미디어 장치에 적용 (생략 시 기본값) |
| `screen` | 모니터, 태블릿, 스마트폰 등 화면이 있는 기기 |
| `print` | 프린터 및 브라우저 인쇄 미리보기 |
| `speech` | 화면 낭독기 등 소리 내어 읽어주는 장치 |

##### | 미디어 특성(Media Feature) — 조건 좁히기 |

| 특성 | 설명 |
| --- | --- |
| `width` / `height` | 뷰포트의 실제 가로/세로 길이를 정밀 타겟팅 |
| `min-width` | 뷰포트 가로 폭이 **지정 크기 이상**일 때 적용 |
| `max-width` | 뷰포트 가로 폭이 **지정 크기 이하**일 때 적용 |
| `orientation` | 화면 방향 감지 (`portrait`=세로, `landscape`=가로) |

##### | 디바이스별 표준 브레이크포인트(Breakpoint) |

| 조건 | 디바이스 |
| --- | --- |
| `max-width: 767px` | 모바일 |
| `min-width: 768px` and `max-width: 1023px` | 태블릿 |
| `min-width: 1024px` | 데스크톱 |

```css
/* 기본(모바일) 스타일 */
body { background-color: #fca5a5; }

/* 태블릿 구간 */
@media screen and (min-width: 768px) and (max-width: 1023px) {
  body { background-color: #6ee7b7; }
}

/* 데스크톱 구간 */
@media screen and (min-width: 1024px) {
  body { background-color: #93c5fd; }
}
```

- 브라우저 창의 가로 폭을 마우스로 조절해보면, 지정한 구간을 넘나들 때마다 배경색이 바로 바뀌는 걸 눈으로 확인할 수 있다.

### | Tailwind CSS — 클래스 조합만으로 스타일링하는 프레임워크 |

- **Tailwind CSS** : 길고 복잡한 미디어 쿼리·CSS 코드를 직접 짜는 대신, HTML 태그의 `class` 안에 **직관적인 유틸리티 클래스**를 조합해서 반응형 웹을 빠르게 설계하도록 돕는 프레임워크.

##### | 연결 방법 (CDN) |

```html
<script src="https://cdn.tailwindcss.com"></script>
```

- `<head>`에 이 한 줄만 추가하면, 별도 빌드 과정 없이 바로 Tailwind 클래스를 쓸 수 있다. (VS Code에 "Tailwind CSS IntelliSense" 확장을 설치하면 클래스 자동완성도 지원됨)

##### | 클래스 네이밍 규칙 |

| 패턴 | 의미 | 예시 |
| --- | --- | --- |
| `[속성]-[크기]` | 기본 스타일 지정 | `p-4`(안쪽 여백 4단위=16px), `w-80`(너비 80단위=320px) |
| `[상태 접두사]:[속성]-[크기]` | 사용자 반응에 따른 조건부 처리 | `hover:bg-blue-600`(마우스 올렸을 때 배경색 변경) |
| `[해상도 접두사]:[속성]-[크기]` | 화면 크기에 따른 반응형 처리 | `md:grid-cols-2`(태블릿 크기 이상일 때 그리드 2열) |

- Tailwind의 **기본 1단위는 4px**이다. (`p-4` = `padding: 16px`, `4 × 4px`)

##### | 크기·여백 실습 |

```html
<body class="bg-slate-100 p-8">

  <div class="w-80 h-[200px] bg-blue-500 text-white rounded-lg border-4 border-blue-700">
    <div class="p-6">
      <h3 class="font-bold text-lg">안쪽 여백 (Padding)</h3>
    </div>
  </div>

  <div class="m-10 w-80 h-24 bg-rose-500 text-white rounded-lg p-4">
    <h3 class="font-bold">바깥 여백 (Margin)</h3>
  </div>

</body>
```

- `h-[200px]`처럼 **대괄호(`[...]`)**를 쓰면, Tailwind가 기본 제공하지 않는 임의의 수치도 직접 넣을 수 있다.

##### | Flexbox / Grid 레이아웃 클래스 |

| Tailwind 클래스 | 대응 CSS | 설명 |
| --- | --- | --- |
| `flex` | `display: flex;` | Flex 컨테이너로 설정 |
| `flex-row` / `flex-col` | `flex-direction: row/column;` | 가로/세로 배치 (`row`가 기본값) |
| `items-center` | `align-items: center;` | 교차축 가운데 정렬 |
| `justify-between` | `justify-content: space-between;` | 주축 양끝 배치 + 중간 균등 간격 |
| `grid` | `display: grid;` | Grid 컨테이너로 설정 |
| `grid-cols-3` | `grid-template-columns: repeat(3, ...);` | 열 3개로 분할 (`grid-cols-1`~`12`) |
| `col-span-[N]` | `grid-column: span N;` | N개 열만큼 영역 차지 |
| `gap-[단위]` | `gap: 값;` | 자식 요소 사이 간격 (`gap-4` = 16px) |

```html
<h2 class="text-xl font-bold mb-4">Grid 3분할 정렬</h2>
<div class="grid grid-cols-3 gap-6">
  <div class="bg-white p-6 rounded-lg shadow-md text-center">1구역</div>
  <div class="bg-white p-6 rounded-lg shadow-md text-center">2구역</div>
  <div class="bg-white p-6 rounded-lg shadow-md text-center">3구역</div>
</div>
```

##### | 반응형 조합 — 모바일 우선주의(Mobile-First) |

```html
<div class="grid grid-cols-1 md:grid-cols-2">
```

- 기본은 **모바일 기준(`grid-cols-1`, 1열)을 먼저 쓰고**, 화면이 커질 때 적용할 예외를 `md:`처럼 해상도 접두사로 덧붙인다. 이렇게 "작은 화면을 기본값으로 두고 큰 화면일 때만 예외를 추가하는" 설계 방식을 **모바일 우선주의(Mobile-First)**라고 부른다.

##### | 클래스는 암기하지 말고 검색해서 찾기 |

- Tailwind는 유틸리티 클래스가 수천 개라 다 외울 필요가 없다. 공식 문서(`tailwindcss.com/docs`)에서 `Ctrl+K`(맥은 `Cmd+K`)로 검색창을 열고, 적용하려는 일반 CSS 속성 이름(`font-size`, `border-radius` 등)을 영어로 검색하면 대응하는 Tailwind 클래스명이 바로 나온다.

### | 헷갈리는 개념 총정리 |

##### | `<section>` vs `<article>` 완전정리 |

- 억지로 구분하려다 잘못 쓰는 것보다, 확신 없을 때는 그냥 `<div>`를 쓰는 게 낫다. 시멘틱 태그는 "정확히 맞을 때만" 가치가 있고, 틀리게 쓰면 오히려 검색엔진이나 다른 개발자를 헷갈리게 만든다.

- **`<section>`의 규칙**
  - **독립체로 여기지 않는다.** (여기가 `<article>`과 근본적으로 다른 점)
  - `<article>`들의 집합소 역할을 하기도 한다.
  - **스타일 적용을 위한 컨테이너(그릇) 역할을 하면 안 된다** — 순수 스타일링용 묶음은 `<div>`의 몫. (`header - div(안에 section) - footer` ✓ / `header - section - footer` ✗)
  - **논리적인 heading(제목) 요소가 있는 경우에만 사용한다** — `<section>` 바로 안에 제목이 와야 한다.
  - `<section>`으로 묶은 콘텐츠는 **재배포할 수 없다.**
  - `<section>`끼리 중첩될 수 있고, 안에 `<article>`이 들어갈 수 있다.

- **`<article>`의 규칙**
  - 전체에서 콘텐츠의 **독립적인 아이템**을 나타낸다.
  - 영역만 분리해서 다른 사이트로 옮겨도 의미를 알 수 있는 콘텐츠를 넣어야 한다 — 즉 **재배포해도 되는 것**을 의미.
  - `<article>`끼리 중첩될 수 있으며, 내부·외부 내용이 서로 관련 있어야 한다.

| 구분 | `<section>` | `<article>` |
| --- | --- | --- |
| 의미 | 특정 주제·목적을 가진 콘텐츠 **그룹** | 독립적으로 배포 가능한 콘텐츠 **블록** |
| 독립성 | 독립적이지 않다 | 독립적이다 (단독으로 의미가 있음) |
| 예시 | '소개', '연락처' 섹션 | 블로그 글, 뉴스 기사, 제품 설명 |

```html
<section>
  <h2>최신 뉴스</h2>
  <article>
    <h3>AI 기술 발전</h3>
    <p>인공지능이 다양한 산업에 영향을 미치고 있습니다.</p>
  </article>
  <article>
    <h3>자율주행차의 미래</h3>
    <p>자율주행 기술이 점점 현실이 되고 있습니다.</p>
  </article>
</section>
```

- `<section>`은 "최신뉴스"라는 **주제를 묶는 역할**, 그 안의 `<article>` 각각은 **독립적인 뉴스 기사**다.

- **뭘 골라야 할지 헷갈릴 때 판단 순서** : ① 의미 없이 단순 구분/디자인용이면 `<div>` → ② RSS 피드로 따로 받아도 이해되면 `<article>` → ③ header/footer/aside/nav/article로 지정하기 어렵지만 제목이 있는 섹션이면 `<section>`

##### | `<a>` vs `<link>` — 다시 정리 |

| 구분 | `<a>` | `<link>` |
| --- | --- | --- |
| 화면 표시 | 클릭하는 링크, 밑줄 쳐진 파란 글씨 | 화면에 아무것도 안 보임 |
| 태그 형태 | 닫는 태그 있음 | 단독 태그 |
| 동작 시점 | 사람이 클릭해야 동작 | 페이지 열리자마자 브라우저가 알아서 가져옴 |
| 용도 | 페이지 이동, 페이지 안 특정 위치(`#섹션`) | 외부 CSS 연결, 파비콘 지정 |

- `<link>`의 `rel` 속성 : `rel="stylesheet"`(스타일시트) / `rel="icon"`(파비콘)
- **파비콘(favicon)** : **favorite + icon**을 합친 말. 즐겨찾기 목록 아이콘이라는 뜻.

##### | 프로토콜(Protocol)이란 |

- 사전적 의미로 "규약", "약속." IT에서는 **컴퓨터·네트워크 장치들이 데이터를 교환할 때 따라야 할 통신 규약**을 뜻한다.

- HTTP(웹 브라우징), FTP(파일 전송), SMTP, TCP, IP 등 각자 다른 목적을 가진 프로토콜들이 존재한다.

- **HTTPS는 HTTP에 데이터 암호화가 추가된 프로토콜**이다. **443번 포트**를 사용해서, 중간에 제3자가 정보를 볼 수 없도록 암호화를 지원한다.

##### | 절대경로 vs 상대경로 — 장단점까지 |

- **절대경로** : `http://`/`https://`로 시작하는, 변하지 않는 전체 주소. 최상위 디렉토리부터 전체 경로를 명시 — 위치에 상관없이 항상 정확하지만, 경로가 길고 파일을 옮길 때마다 전부 수정해야 함. 장점은 폴더 구성을 눈으로 쉽게 볼 수 있다는 것.
- **상대경로** : 현재 파일 위치를 기준으로 목적지를 표시. 서버·폴더를 옮겨도 재설정이 필요 없다는 장점이 있지만, 폴더 전체 구성을 한눈에 볼 수 없다는 단점이 있다.

##### | `display: none`을 줬는데 안 사라질 때 체크할 것 |

1. **선택자가 맞는 요소를 정말로 가리키고 있는지** — 클래스명 오타, 다른 요소를 겨냥하고 있는 건 아닌지 개발자도구 Elements 탭에서 확인.
2. **더 명시도가 높은 다른 규칙이 있는지** — Styles 패널에서 `display: none;`에 취소선이 그어져 있다면 이 경우다.
3. **CSS 파일이 실제로 적용되고 있는지** — `<link>` 경로 오류나 캐시 문제일 수 있음 (강력 새로고침으로 확인).
4. **자바스크립트가 `style.display`를 다시 바꾸고 있는지** 확인.

##### | Elements 탭 구조 이해하기 |

- **element**는 "성분, 요소, 구성"이라는 뜻. Elements 탭은 **현재 페이지의 구성 요소를 확인**하는 탭으로, 전체 구조를 훑기보다 **특정 요소 하나의 구조·스타일을 확인**할 때 주로 쓴다. 왼쪽엔 HTML 구조, 오른쪽엔 CSS(Styles/Computed) 구조가 나온다.

##### | 그 외 짧게 정리하는 것들 |

- **`:nth-of-type(1)`** : 같은 태그 유형 중 **1번째** 요소 선택. `:nth-child`와 달리 부모 안에 다른 태그가 섞여 있어도 같은 태그끼리만 순서를 센다.

- **`min-width: 100px`의 용도** : `width`는 "기본 크기"고, `min-width`는 "무슨 일이 있어도 이보다 작아지지 말라"는 하한선이다. `flex-shrink` 등이 아무리 줄이려 해도 `min-width`보다는 안 줄어든다. (09-18 클론코딩 노트의 `min-width: 0`과는 정반대 용도 — "줄어들지 못하게 막는" 게 원래 역할)

- **`justify`의 뜻과 `flex`/`justify-content`의 차이** : `justify`는 "정렬하다"는 뜻의 영어 단어. `flex`(`display: flex`)는 "이 부모를 Flexbox로 만들어라"는 **레이아웃 모드 선언**이고, `justify-content`는 그 안에서 "어떻게 정렬할지" 정하는 **세부 규칙**이다. `flex` 없이 `justify-content`만 쓰면 아무 효과가 없다.
