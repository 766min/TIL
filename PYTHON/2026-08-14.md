### - 변수와 동적 타이핑

| 변수란 ? 

- x = 10 이라고 코드를 작성하면 메모리 공간에 10 이라는 데이터(객체)가 먼저 생성되고 x라는 변수는 10의 메모리 주소를 참조하는 이름표 역할이다.

| 참조란 ?
- 변수를 참조한다 = 변수가 가리키고 있는 값을 사용한다.

```python
x = 10
print(x)
```
여개서 x를 참조하고있다.고 말할 수 있다.

| 변수명명규칙

- 변수명은 영문 대소문자, 숫자, 언더바로만 구성가능하다. 그치만 관례적으로 변수명은 보통 대문자보다는 소문자를 많이 사용
- 숫자로 시작할 수 없다.
- 공백을 포함할 수 없다.
- 파이썬이 이미 예약해둔 핵심 키워드(if, for, while, True, False등)는 변수명 사용 불가

-> 여러 단어를 조합해 변수명을 지을 때는 언더바로 연결하는 스네이크 케이스를 표준으로 권장한다. (`user_age`, `total_price` 등과 같이)

 | 동적 타이핑

- 실행하면서 자료형이 결정되고 바뀌는것
`x = 10`을 입력했을때 python은 알아서 '10은 정수네 x가 지금 정수구나'라고 판단하고 바로 `x = "Hello"`라고 하면 '이번엔 문자열이구나'라고 실행하면서 알아서 타입을 판단해준다. 다른언어에서는 `int x = 10;`과 같이 x가 정수임을 알려줘야하는데 파이썬은 알아서 자료형을 판단해준다.

- 트레이드오프 : '하나를 얻으면 다른 하나를 포기해야하는 관계' 즉 동적타이핑에서 생기는 편리함과 코드의 간결함을 얻는 장점과 대규모작업의 경우 타입 관련 오류를 실행 전에 발견하기 어려울 수 있다는 단점도 생길 수 있다.

### - 변수 재할당과 메모리 전환

- 가비지 컬렉터 : `age = 20` `age = 30` 으로 age변수가 가리키는 객체에 새로운값을 재할당을 했을때 age라는 변수에 할당된 데이터 값이 변경되었는데 즉, 기존의 20 객체를 더 이상 아무도 참조하지 않는 상태가 되면, 기존에 있던 20은 파이썬의 자동 메모리 관리 시스템인 가비지 컬렉터로부터 자동수거된다.

- 재할당 : age에 30이라는 새로운 값을 다시 넣는것

- 메모리 전환 : 그 결과 age가 20객체가 아니라 30 객체를 가리키게 되는 변화자체다.

| 메모리를 위한 내장 함수

- type() : 변수가 참조하고 있는 데이터의 자료형을 알려준다.

    - `age = 20`
`type(age)` `<class 'int'>` => age가 참조하고 있는 20객체의 자료형은 int 정수라고 알려준다.

- id() : 데이터(객체)가 저장된 메모리의 주소값을 보여준다.

    - `age = 20` `id(age)`를 하면 '140735...'이렇게 age가 참조하고있는 20객체가 가지고있는 주소값을 보여준다.

** 출력할때 파이썬인터프리터나 주피터에서는 `type(age)`, `id(age)`를 해도 결과가 출력되지만 ' .py'파일인 파이썬 코드를 저장해놓는 파일에서 입력할때는 `print(type(age))`, `print(id(age))` 처럼 print문을 입력해야 출력이된다. **

### - 자료형

- 수치형 자료형 : 정수(int), 실수(float)

- 문자열 자료형 : str

    - 글자 앞뒤를 작음따옴표나 큰따옴표로 감싸주어야 글자 데이터 문자열로 인식가능하다.

- 논리형 자료형 : 참(True)과 거짓(False) bool : 첫 글자는 반드시 대문자로 작성해야한다.

    - 참 True : 0이 아닌 숫자, 값이 존재하는 상태

    - 거짓 False : 숫자 0, 빈문자열 "", 빈 리스트 [], None 등의 값이 비어있는 상태

### - 명시적 형변환 : 내가 직접 자료형을 바꾸는것

- int(값), float(값), str(값), bool(값)

    - 문자열을 숫자로 변환 : `num_str = "100"` `converted_int = int(num_str)` 은 num_str 변수가 가리키는 100객체는 쌍따옴표안에 있으니 문자열형태인데 `int(num_str)`로 정수형 형태로 변환했다.

    - 숫자를 문자열로 변환 : `age = 20` `message = " 나이 :" + str(age)`를 하면 age 변수에들어있는 20객체는 정수인데 `str(age)`로써 문자열 형태로 변환하였다.

    - 실수형을 정수형으로 변환 : 소수점의 실수형을 정수형으로 변환할때는 소수점 이하의 자리가 반올림, 반내림이아닌 버림처리된다.

    -`int("100")` 문자열 -> 정수
    `float("3.14")` 문자열 -> 실수
    `str(100)` 정수 -> 문자열
    `int(3.14)` 실수 -> 정수 '3 만 남음'
    `bool(1)` 정수 -> 불리언 (참과 거짓을 나타냄 1(값이있음)은 True인것이다. 0일경우만 False)
    `list("abc")` 문자열 -> 리스트 ['a', 'b', 'c']형태로되는것
    `tuple([1, 2, 3])` 리스트 -> 튜플 (1, 2, 3)이되고 튜플이기 때문에 값을 변경할 수는 없다.

### - 묵시적 형변환 : Python이 상황에 따라 알아서 자료형을 바꾸는것

- `x = 10` `y = 3.5` `result = x + y` 여기서는 x는 정수이고 y는 실수이다. 그런데 이둘을 더할려면 python은 자료형상태를 맞춰야하는데 이를 자동으로 정수10을 실수10.0 처럼 처리해서 계산한다 그러면 result에는 13.5가 들어가게된다.

- 업캐스팅 : 작은 범위의 자료형을 더 큰 범위의 자료형으로 바꾸는 것이다. 대표적인 예로는 int -> float로 변환되는것.

| 형변환시의 에러 : ValueError

- `val = "20세"` `int(val)` 은 "20세"가 따옴표안에 들어가있지만 숫자와 문자가 합쳐져있는 순수 숫자가 아닌상태인데 이를 정수형으로 바꿀려하면 ValueError발생한다.

- `a = "3.14"` `int(a)`를 하면 문자열상태인 3.14를 정수로 바로 바꿀려해서 에러가 발생한다. 그러므로 정수형으로 변환하고싶다면 float(a)를 거치고나서 int(float(a))처리를 해줘야 정수형으로 변환이 가능하다. 여기서 int(a)를 바로 해주면 되는줄 알았지만 int(float(a))를 해줘야한다는걸 알게됐다.

- `str.isdigit()`메서드 : 문자열의 내용이 순수하게 숫자로만 구성되어 있는지 검사하여 참/거짓을 반환하는 기능을 가지고있다.
```python
time = "10시"

if time.isdigit():
    int(time)

print(time.isdigit())
```
하면 False가 나온다. 왜냐면 .isdigit()메서드는 문자열이 순수숫자가 맞는지 아닌지에대해 검정해주는데 time안에있는 문자열은 10 과 시 라는 숫자와 문자가 합쳐있기때문에 False룰 출력하는것이다.

### - 연산자

- 산술 연산자 : 항상 실수형으로 반환하는 특징이있다.(4/2 결과는 2가아닌 2.0으로)

    - +, -, *, /, //(몫 연산자), %(나머지 연산자), **(거듭제곱 연산자)

    - 복합 대입 연산자 : `x = x + 10`과 같이 변수가 중복되는 구조를 `x += 10`으로 축약한다. '+=, -=, *=, /=, //=, %='

- 비교 연산자 : 결과는 불리언자료형인 True나 False로 반환된다.

    - 동등 비교 연산자 : '=='은 두 값이 서로 같으면 True, 다르면 False 반환이고 '!='는 두 값이 서로 다르면 True, 같으면 False를 반환한다.

    - 대소 비교 연산자 : >, <, >=, <= 로 초과, 미만, 이상, 이하인지를 식별하여 True와 False를 반환한다.

    - 문자열 데이터도 대소 비교가능하다. 이는 알파벳순서(문자의 유니코드 값)로 식별한다.

- 논리 연산자 : and, or, not

    - and : 각 항의 조건이 모두 True -> True 하나라도 False -> False

    - or : 각 항의 하나라도 True이면  True를 반환하고 둘 다 Fasle일때만 False를 반환한다.

    - not : 반대로 뒤집는것 ! 예로 1은 True지만 not을 만나면 False가 된다.

| 단락 회로 평가 : 논리 연산을 하다가 결과가 이미 결정이나면 뒤쪽 코드는 더이상 보지않는다. and 연산자는 앞에서 False가나오면 어차피 False이기때문에 뒤쪽을 더이상 보지 않고 or 연산자는 앞에서 True가 나오면 어차피 True가 되기 때문에 뒤쪽을 더 보지 않는다.

- 연산자 우선순위 : 

대입 연산자(=) < 논리 연산자(or < and < not) < 비교 연산자(>=,>,..) < 산술 연산자(+, -, *, //..)

- 만약 이를 무시하고 다른 연산을 우선시시키고 싶다면 소괄호를 해당 문구로 감싸주면 우선순위로 둘 수 있다. 소괄호 사용을 추천한다.

### - 문자열 형식화 방식

- % 연산자 방식 : %s(문자열), %d(정수), %f(실수)이런식으로 기호로 자리를 만들어두고 변수를 순서대로 대입한다.

    - %5d 처럼 숫자를 사이에 넣으면 5칸을 확보하고 오른쪽 정렬을해라 라고 지정할 수 있다.

    - %.2f 처럼 점과 숫자를 사이에 넣으면 소수점 소수점 둘째자리까지 표기하라고 지정할 수 있다.

    - 이 방식은 기호 매칭이 엄격해서 에러가 자주 날수있다..

- str.format() 메서드 방식

- 중괄호를 사용하여 문자열 안에 값을 넣을 위치를 지정하고 넣을 값은 순서대로 작성한다.

```python
name = "철수"
age = 20

print("이름은 {}이고 나이는{}살 입니다.".format(name, age))
```
`이름은 철수이고 나이는 20살 입니다.` 로 출력이된다.

- 이 방식은 코드가 길어지고 대입할 변수가 많아지면 코드가독성이 떨어진다.

- f.string 방식
`print(f"금액 :{15000:>8,}원")` 하면 출력이 `금액 :        15,000원`처럼 >8 은 8칸확보후 오른쪽 정렬해라 이고 뒤의 컴마는 천단위마다 컴마를 찍어라는 뜻이다.

```python
name = "철수"
age = 20

print(f"내 이름은 {name}이고 나이는 {age}살이다.")
```
`내 이름은 철수이고 나이는 20살이다.`

f를 붙였고 각자의 변수명에맡게 {}중괄호안에있는곳으로 잘 찾아 들어갔다.

- 디버깅 조절자 (=) : 변수의 이름과 현재값이 바로 출력된다.
```python
score = 95
print(f"{score=}")
```
`score=95` 가 출력된다.

- strftime메서드는 날짜/시간 데이터를 문자열로 변환해줄수있는데 형태/형식은 정해진게없다. 그래서 print문에서 %Y %m %d 로 만들어달라고 형식을 정해주는거다.
- 함수 = 독립적으로 사용하는 기능
- 메서드 = 객체에 소속되어 있는 함수

#### Q1. 다음 중 이터러블(Iterable)과 이터레이터(Iterator)에 대한 설명으로 옳은 것은?

-> 정답 ! 이터레이터는 __iter__ 메서드를 통해 생성되며, __next__ 메서드로 다음 요소를 순차적으로 반환한다.

ㄴ> 풀이 ! 이터러블 객체는 __iter__ 메서드를 통해 이터레이터를 생성하고, 생성된 이터레이터는 __next__ 메서드로 다음 요소를 하나씩 반환한다. 이터러블 자체는 __next__ 갖지 않으며, 순회가 끝나면 None이 아닌 Stopiteration 예외가 발생한다.

이터러블은 리스트, 문자열, 딕셔너리처럼 내부 요소를 하나씩 꺼내어 순회할 수 있는 모든 객체를 의미한다. __iter__ 메서드를 가지고있어서 이터레이터를 만들 수 있다. 이터레이터는 이터러블 객체에서 요소를 순서대로 꺼내는 포인터 역학을 하는 객체이다. 다음요소를 가리키는 __next__ 메서드를 가지고 있어서 한번에 하나씩 데이터를 메모리에 불러와 처리하는 동작 방식을 가진다. 

즉, 

이터러블 = '하나씩 꺼내줄 수 있는 것'
이터레이터 = '실제로 하나씩 꺼내주는 놈'
__iter__ 메서드는 바구니에담긴걸 꺼내갈사람을 불러
__next__ 메서드는 그거꺼내고 다음거꺼내고 현재위치를 기억해

```python
numbers = [1, 2, 3]

for n in numbers:
    print(n)

-----------------------

numbers = [1, 2, 3]

it = iter(numbers)
```

첫번째 코드를 봤을때 여기서 이터러블은 numbers 자체다 왜냐 지금 리스트 형태로 되어있기때문에 꺼낼 준비가 되있다. 그리고 두번째 코드에서 이터레이터는 it 변수가된다. 이터러블은 데이터를 보관/제공할수있는 역할이고 이터레이터는 현재 어디까지 왔는지 기억하면서 꺼낸다.

Q5. 다음 중 import, from, as 키워드에 대한 설명으로 옳지 않은 것은?

{선지}
```
a. import 키워드로 모듈을 불러오면 모듈이름.함수이름() 형태로 호출해야 한다.

b. from 키워드를 사용하면 모듈 이름 없이 함수 이름만으로 곧바로 호출할 수 있다.

c. as키워드는 모듈이나 함수에 별칭을 부여할 때 사용한다.

d. from 키워드를 사용하면 모듈 전체를 통째로 불러와야 하므로 import()보다 항상 메모리를 더 많이 사용한다.
```

[ 내 오답 ]
a번 선택함

[ 헷갈린 막혔던 부분/이유 ]

a. 선지는 import로 모듈을 불러올때 'import math'이런식으로 모듈이름만 적으니 .함수이름()이 붙은게 잘못됐다고 생각했다.

b. 선지는 from도 'from math import sqrt'식으로 모듈이름을 입력하기때문에 이선지도 헷갈렸다.

c. as는 'import math as m'식으로 모듈이름에만 별칭을 부여할 수 있는거라 생각했다.

그래서 전체적으로 선지를 다 헷갈려함. 그중에서도 a선지가 .함수이름()안붙는게 확실했다고 생각해서 선택했다.

[ 정답 ]

d. from 키워드는 모듈 전체가 아닌 필요한 특정 함수나 클래스만 선택적으로 가져오는 방식이므로, 모듈 전체를 불러오는 import보다 메모리를 더 많이 쓴다는 설명은 틀렸다. 

[ 알게된 부분 ]

a. import.math 를했다고 끝이아니라 그다음에 math.sqrt(16)이 호출형태인것이다. 즉, math.sqrt(16)처럼 모듈이름.함수이름()형태로 모듈 안의 함수를 사용할 수 있다. math모듈을 가져오고 그 안에 있는 sqrt함수를 사용한다는게 하나의 흐름이다. import 는 가져왔고 math.sqrt()는 가져온걸 사용한다.

b. 만약 'from math import sqrt'를 입력해서 math모듈을 불러와서 sqrt함수를 가져왔기때문에 다음에 sqrt함수를 사용할때는 from부터 입력할 필요없이 바로 sqrt(16)이러식으로 입력하면 바로 함수가 실행된다. (단,프로그램을 다시 실행하면 from부터 쳐서 불러와야한당.)

c. 'import math as m' 는 math모듈을 m별칭으로 부르겠다는거고 'from math import sqrt as s'를 입력하면 math 모듈에서 sqrt함수를 가져오는데, 앞으로는 sqrt대신 s라고 부르겠다고 하는것이다. 결국은 as 키워드는 모듈에도 함수에도 별칭을 부여할 수 있다.!!
