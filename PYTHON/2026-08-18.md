## 함수

- 매개변수 : 함수를 정의할 때 괄호 안에 적어두는 이름표(변수).

- 인수/인자 : 함수를 실행(호출)할 때 괄호 안에 실제로 넣을 값

- 원소 : 리스트나 배열안에 있는 데이터 . 구성요소들 각가을 원소라한다.

- 위치 인수 : 함수를 호출할 때 정의된 매개변수의 순서대로 인수가 들어가는것

- 키워드 인수 : 인수를 전달할때 매개변수명=값 형태로 이름을 명시하여 매개변수의 위치 상관없이 호출 가능하다. (중요! - 위치 인수와 함께 사용될때는 반드시 위치인수가 먼저 작성되어야한다.)

- 가변인수(*args) : 여러개의 인수를 가져올수있게끔 해준다.

- 키워드 가변 인수(**kwargs) : 여러개의 인수를 가져오면서 이름표도 붙여서 가져온다.

- return문 : 함수가 계산할 값을 밖으로 내보내주는 것

- 복수 데이터 반환 : return문에 여러개의 값을 한번에 반환가능하다. 예. `return plus, minus` (자동으로 튜플로 묶여서 나감) 필요에따라 여러개로 나눠서 받을 수도 있다.

[ 예제 1 ]
```python
def get_average(*scores):
    if len(scores) == 0:
        return 0

    total = sum(scores)
    avg = total / len(scores)
    return avg

result1 = get_average(80, 90, 100)
result2 = get_average(75, 60, 88, 92, 100, 45)

print(f"3과목 평균 점수: {result1:.2f}")
print(f"6과목 평균 점수: {result2:.2f}")
```
[ 풀이 ]

일단 get_average라는 함수를 정의하고 매개변수는 scores인데 가변인수*를이용해서 인수는 여러개 넣을거다 그리고 if문은 len메서드를 이용해 그 scores의 길이를 제고 그게 0 일시에 return 0 0을 반환한다. 그리고  total이라는 변수를 지정하고 sum함수를 이용해서 scores의 합계를 저장하고 avg라는 변수를 지정해서 scores의 갯수 나누기 총합계인 total을 나눈다 그리고 그 나눈 평균값을 return한다. result1변수에는 get_average함수를 호출하고 가변인수로 지정햇으니 80, 90,  100 인수 세개를 넣응ㄹ수있었고 result2변수에는 get_average함수를 부르고 마찬가지로 가변인수이니 75, 60 ,88, 92, 100, 45 6개의 값을 넣엇다 그리고 print문은 3과목 평균점수에는 result1 에들어가고 소수점 둘째자리까지 표시해 출력해라  result2도 마찬가지이다.

[ 몰랏던 점 ]

근데 if문에 0 일때 0을 반환한다는건 왜그런가??

-> 만약 *scores로 점수를 받아야되는데 아무점수도 넣지않고get_average()만 해서 함수만 불렀다면 (빈튜플()이되니깐 길이가 0이된다.) 갯수가 0이면 나눌수없어서 에러가난다. 그래서 미리 if문으로 0이되면 0을 반환할수잇도록 안전장치를 만든것이다.

```python
def calculate_values(a, b):
    plus = a + b
    minus = a - b
    return plus, minus # 자동으로 튜플 구조로 묶여 반환됨

# 호출 및 각 변수 매핑 식별

print(f"전체 반환 구조: {all_result}")
```

res1, res2가 어떻게 plus, minus값이 되는가?

### | lambda 람다 함수

- 람다 함수 : def으로 길게 함수를 만들지않고 즉석에서 그냥 이름안붙이고 만들어도되는 짧은 익명함수

`변수명 = lambda 매개변수들 : 반환할 값`

만약 반환할 값이 없다면 lambda함수에서는 문법오류가 생긴다. 그래서 아무값도 안돌려주고 그냥 동작만하겠다면 람다함수가 아닌 일반함수def를 사용해야한다.

- map() : 리스트 같은 자료의 모든 인수에 똑같이 계산을 해주는것
```python
nums = [1, 2, 3, 4]
result = list(map(lambda x: x * 2, nums))
print(result)  # [2, 4, 6, 8]
```
[ 풀이 ]
nums변수에 [1, 2, 3, 4] 라는 리스트가 들어잇고 result변수에 담을 내용은 map()메서드를 이용할거다 어떤거냐면 리스트 안의 내용을 x라는 매개변수에 하나씩 담고 어떤걸 반환할거냐면 그 하나씩 들어오는 x에 2씩 곱해라 그거를 list(  안에서  ) 실행햇으니 출력은  다시 리스트형태에 담겨 출력된다.

``변수명 = map(lambda 매개변수들 : 반환할 값 (, 람다함수에 적용할 대상 리스트)))``
map( )은 두가지의 내용을 받는다(함수코드, 반복가능자료)

- filter() : 리스트 같은 자료에서 조건에 맞는 인수만 골라내는것
```python
nums = [1, 2, 3, 4, 5, 6]
result = list(filter(lambda x: x % 2 == 0, nums))
print(result)  # [2, 4, 6]
```
[ 풀이 ]

### | 클로저

- 일급 객체 : 변수에 대입할 수 있고, 다른 함수의 인수로 전달할 수 있으며, 함수의 결과값으로 반환될 수도 있는 자격을가진 대상
- 고차 함수 : 함수를 인자로 받거나 함수를 반환하는 즉, 함수와 함수를 다루는 함수 map( ), filter( ), sorted( )같은 함수

- 클로저 : 함수가 끝났는데도 그 함수 안에서 쓰던 변수를 기억하고 있는 함수
```python
def outer_func(msg):
    def inner_func():
        print(f"메시지: {msg}")
    return inner_func

printer = outer_func("안녕")
printer()  # 메시지: 안녕
```
[ 풀이 ]

outer_func함수가 만들어졋고 매개변수는 msg가 들어가잇다 그리고 아직 실행하지않고 inner_func함수를만들엇고 이게 실행되면 print문 메시지 : 하고 msg값이 출력된다. 그리고 return문은 그 inner_func를 반환한다.  printer변수에 outer_func함수를 넣고 msg에 “안녕”을 넣는다. 

outer_func실행이 끝나면 그안의 지역변수인 msg는 사라져야한다. 근데 inner_func가 msg를 계속 기억하고잇다 이를 클로저라고 말한다.

[ 몰랐던 점 ]

outer_func가 실행됐다는게 printer변수지정햇을때 실행됐다는게 맞는건지., 그리고 inner_func에는 왜 괄호안에 비어잇는건지 그게 무슨의미이고 뭐가 다른건지모르겟다.맨밑에 printer ()이것도 괄호가 무슨뜻인지모르겟다

-> `printer = outer_func("안녕")` 여기서 outer_func(msg)가 실행된것 그래서 매개변수에 “안녕”문자열이 들어갔따.  그 실행결과로 inner_func라는함수가 반환되고 그게 printer변수에 담겼다. 그로인해 printer는 내부함수를 가리키는 변수가 되었다.

또 inner_func( )처럼 괄호안이 비어있는건 매개변수가 없는 함수라는 뜻인데 여기서 inner_func는 실행할때 외부에서 값을 받을 필요가 없고 이미 outer_func에서받은 msg를 기억해서 쓰는 구조이다.

또 마지막에 printer( ) 에서는 printer변수는 지금 inner_func를 가리키고있다. 그래서 괄호를 붙여서 그 함수를 실행시키겠다. 그래서 메시지 : 안녕 이 출력되는것이다.

### | 데코레이터 @

- 데코레이터 : 원래 함수에 추가 기능을 덧붙이는 포장지
```python
def login_required(func):
    def wrapper():
        print("로그인 확인 중...")   # 실행 전 기능
        func()                      # 원래 함수 실행
        print("로그인 기록 저장!")   # 실행 후 기능
    return wrapper

@login_required
def show_profile():
    print("사용자 프로필 화면입니다.")

```
[ 풀이 ]

@이 골뱅이는 이 함수에 데코레이터를 씌워줘라는 표시

wrapper()함수 : 원래 함수를 감싸서 실행 전후에 추가기능을 넣는 함수

저 골뱅이부분은 기존 원본이었던 심심했던 show_profile함수가((이함수만실행하면 사용자 프로필 화면입니다.)만 출력됨 그래서 앞뒤로 로그인확인중 , 로그인 기록저장같은 말을 넣어서 좀더 다채롭게 보여주기위해 데코레이터 함수를 사용하는것) login_required함수안에 들어갈거다 그래서 login_required(show_profile)모양이된다고 정의해둔것

[ 몰랐던 점 ] 

그러면 저 데코레이터 함수내용부분에 func말고 show_profile이 들어가야되는거아닌가?

데코레이터는 여러 다른 함수에도 재사용할수있게만들어진건데 func() 대신 show_profile 함수 특정함수를 지정한다면 그 함수에서  밖에 사용이안되므로 굳이 데코레이터를 사용할필요가없게되는것 다른 함수에서 저 로그인 확인중 로그인 기록저장같은 프린트문구를 사용할수도 있으니 func로써 여러함수가 사용할수있게끔 열어둔것이다.


### [ 자동 로깅 실습 ]
```python
def auto_logger(original_func):
    def wrapper(*args, **kwargs):
        print("호출된 함수명:", original_func.__name__)
        print("주입된 인수 데이터:", args, kwargs)

        result = original_func(*args, **kwargs)

        print(original_func.__name__, "함수의 정상 연산이 종료되었습니다.")
        return result
    return wrapper


@auto_logger
def login_process(user_id, password):
    if user_id == "admin" and password == "1234":
        return "로그인 성공"
    else:
        return "로그인 실패"


login_status = login_process("admin", password="password99")
print("결과:", login_status)
```
\_\_name\_\_ :  함수이름을 문자열로 저장해둔 속성

original_func.__name__ : 원래함수이름을 문자열로 알려준다. 여기서는 original_func인 원본함수가  login_process니깐 “login_process”가 출력된다.  그러면 “호출된 함수명: “login_process””가 출력된다. 그리고 다음 “주입된 인수 데이터: “ 부분에는 밑에서 `login_status = login_process("admin", password="password99")` 를 했으니깐 args자리에는 “admin”이 들어가고 kwargs에는 {”password”: “password99”}가 들어간다. 그래서 “주입된 인수 데이터: {’admin’,) {’password’ : ‘password99’}가 출력된다. 아직 login_process()자체는 실행하지 않앗음 

`result = original_func(*args, **kwargs)`는 원래 함수를 실제로 실행해라. 그리고 그 결과를 result에 저장해라 즉, 원래함수인 login_process를 실행하고 결과 {’admin’,) {’password’ : ‘password99’}를 넣어라 `login_process("admin", password="password99") `이모양을 실행하는것. 그럼 현재 값이 user_id 에는 "admin"이 들어가있고 password에는 "password99"가 들어가있다. 그러면 저 원본함수 login_process함수의 if문에서 user_id == "admin"은 맞는데 password == "1234"가 틀리게 된다. 그러면 else문 . 로그인 실패를 출력함 그러면 `result = original_func(*args, **kwargs)` 이거에서 orginal_func인 login_process가 로그인 실패를 반환했으니까 result = “로그인 실패”가 된것이다.  그래서 다음 코드인 print(original_func.__name__, "함수의 정상 연산이 종료되었습니다.")여기서 login_process 함수의 정상 연산이 종료되었습니다. 가 출력된다. 또 return result 이므로 결과를 다시 돌려준다. 즉, 아까 원래 함수가 만들어낸 결과를 다시 밖으로 돌려줘라 “로그인 실패”를 반환한다. 근데 그다음으로 return wrapper가있네 이건 wrapper()가아니라 실행하라는게 아니다. auto_logger가 끝났으니까 wrapper라는 함수를 밖으로 넘겨라. 그리고 진짜 마지막실행인`login_status = login_process("admin", password="password99")`

## | 이터레이터와 제너레이터

- __iter__()

- 이터러블 : 데이터가 여러 개 들어있어서 하나씩 차례대로 꺼내주는것 리스트, 튜플, 문자열, 딕셔너리 등

`for item in 리스트` 처럼 반복문에 바로 넣을수 있는게 전부 이터러블!!

- 이터레이터 : 이터러블에서 데이터를 하나씩 뽑아내는 작업

\_\_next\_\_()함수를 쓸 수 있다. 이 함수를 호출할때마다 그다음 데이터를 하나씩 보여준다. 들어있던 데이터를 다 사용하고나면 재사용할수없다. 다시 처음부터 데이터를 보고싶다면 이터레이터를 새로 만들던가해야됨.


- 제너레이터 : 데이터를 미리 전부 만들어두는게아닌 필요할때마다 하나씩 즉석에서 만드는 함수

장점 
1. 메모리 절약
2. 무한한 데이터 표현이 가능

- yield 키워드 : 제네레이터를 만들때 사용하는 키워드

return은 값을 반환하고 나면 함수가 완전 끝나버리지만 yield는 값을 반환한 후에도 함수가 죽지않고 그상태 그대로 잠시 멈춰있다.
