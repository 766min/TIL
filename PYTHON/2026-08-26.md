| 텍스트 파일 읽기 함수 3총사

- read() : 파일 전체 내용을 하나의 거대한 문자열로 통째로 가져온다.
  - 파일이 작을때는 편하지만 클때는 메모리 부족을 유발할 수 있다.

- readline() : 호출할때마다 다음 줄을 순서대로 하나씩 가져온다.
  - 대용량 파일을 메모리 부담없이 조금씩 처리할 때 유용
    - .strip()으로 줄바꿈 문자를 제거하며 주로 쓴다.

- readlines() : 파일의 모든 줄을 읽어서 각각을 하나의 요소로 가지는 '리스트'형태로 반환한다.

#### - CSV, JSON

- CSV : 데이터를 가로줄(행)과 세로줄(열)이 있는 표모양으로 저장하되 칸과 칸 사이를 쉼표기호로 구분해서 적어둔 가장 가볍고 단순한 텍스트 파일 포멧이다.
  - 파이썬 프로그램 안으로 CSV파일을 가져오면 컴퓨터는 이걸 통째로 '리스트 안에 리스트가 들어있는 2차원 리스트 구조'로 바꿔서 인식한다.


- JSON : 데이터의 이름(key)과 값(value)를 중괄호 안에 쌍으로 짝지어 담아, 복잡하게 얽힌 계층 구조를 아주 직관적이게 표현하는 텍스트 포멧
  - 외부에서 JSON을 파이썬안으로 가져오면(json.load, json.loads) 파이썬은 딕셔너리와 리스트 객체로 변환해준다.

#### - 직렬화 : 내보내기
  - 파이썬 메모리안에서 딕셔너리나 리스트처럼 복잡하게 얽혀 있는 데이터객체를 한 줄로 쭉 늘어선 형태로 펼친다.
  - json.dump()
  - json.dumps()

#### - 역직렬화 : 가져오기
  - 파일이나 텍스트에 들어있던 일렬 형태의 데이터가 파이썬이 곧바로 계산하고 조직할 수 있는 원래의 딕셔너리.리스트 객체로 역직렬화(조립)한다.
  - json.load()
  - json.loads()

```python
with open("source.txt", "r", encoding="utf-8") as infile:
    lines = infile.readlines()  # 모든 줄을 리스트로 읽어옵니다.

with open("result.txt", "w", encoding="utf-8") as outfile:
    # enumerate를 활용해 줄 번호(1부터 시작)와 내용을 함께 가공합니다.
    for index, line in enumerate(lines, start=1):
        outfile.write(f"{index}번 줄: {line}")

with open("result.txt", "r", encoding="utf-8") as checkfile:
    print(checkfile.read())        
```
- w모드를 사용해서 source.txt파일을 만들고
- r읽기 모드로 열고 infile.readlines()를 실행한다. 그러면 파일 안에 있던 3줄이 각각 하나의 문자열 요소가 되서 리스트형태로 올라온다.
- 새 파일인 result.txt를 w모드로 열고
- enumerate(lines. start=1) 은 enumerate가 리스트의 요소들을 하나씩 꺼내면서 1번부터 시작하는 순차적인번호 (인덱스) 를 자동으로 붙여주는 도구다  start옵션을 이용해서 인덱스시작값을 설정할 수도 있다.
- outfile.write는 새로운파일(outfile)에 텍스트 내용을 직접 기록할때 사용하는 함수이다.
