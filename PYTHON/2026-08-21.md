### return문에 대해서

마지막에 그냥 함수명으로 끝내는건 그 함수를 실행시키는게아니고 그냥 가리키는것일뿐 함수명에 괄호를 붙여줘야 그 함수가 실행이된다.

return 뒤의 내용에 함수 밖으로 내보내고싶은내용을 적어주면된다.

함수 = 일을하는기계
매개변수 = 기계에 넣어주는 재료
return = 기계가 만든 결과를 밖으로 꺼내기

| 함수를 쓰는이유

  - 한 번 만들어 놓으면 반복해서 사용이 가능하다.
  - 복잡한 코드를 한덩어리로 숨기기 가능하다.
  - 필요할 때 이름만 불러서 사용이 가능하다.

그냥 함수마지막에 return만 입력한 경우는 결과를 보내지않고 함수를 끝낸다. 보통 이렇게 하는 경우는 잘 없고 조건문같은거의 중간에 return을 넣어 함수를 멈추는 역할로 있는경우다.

[return을 사용 예]
```python
def add(a, b):
    result = a + b
    return result #result를 반환했기때문에 a+ b 가 함수밖으로 꺼내져서 다른데서 계산이 사용가능한거다.

answer = add(3, 5) #매개변수 a와 b에 값을 전달함 그값이 answer변수에 저장되었다
print(answer) #print문으로 출력 그럼 출력 결과는 8이 출력된다.
```
이 함수는 a와 b라는 숫자를 받아서 더한 다음, return result를 통해 더한 결과를 함수 밖으로 보내준다. 

[return문을 만나면 함수가 끝나는 예]
```python
def test():
    print("첫 번째")
    return
    print("두 번째")
```
이 함수를 실행하면 첫 번째만 출력이된다. 왜냐면 return문이 중간에 껴있으니깐 return은 만나는 순간 함수가 끝나서 밑의 print문이 실행되지않아 두 번째는 출력되지 않는다. 그래서 이렇게 중간에 return문으로 함수를 끝내는건 조건문과 함께 사용할 때 유용하다.

[return문으로 조건문유용하게 쓰기]
```python
def check_age(age):
    if age < 14:
        return #return뒤에 아무것도 반환하지않으니깐 True가되면 사실 None을 반환하는거다.
    print("입장할 수 있습니다.")

age = check_age(11) #그러면 여기서 age에는 None이 들어오기때문에 print를 해도 None이 출력된다.
print(age)
```
이렇게 age에 11을 전달하면 조건문에서 11 < 14 즉 True가 되므로 return을 만나서 함수가 바로 끝난다. 그러면 print문이 실행되지않으므로 "입장할 수 있습니다."가 출력되지않는다. 이렇게 return뒤에 아무것도 적지않은 return만 사용하는 경우는 어떤결과를 밖으로 내보내지는게아니라 그냥 함수를 끝내는거다. 그래서 반환한값이 없기때문에 None을 반환하며 저기서 출력은 None이 된다. 만약 age에 15가 들어갓다면 False가 되고 return문은 실행되지않고 if문을 빠져나온다. 그러면 다음줄인 print문이 실행되서 입장할 수 있습니다. 가 출력된다!! 근데 여기서 이렇게 조건문이 Fasle가되서 return은 만나지않는데도 밑의 print에서 입장 할 수 있습니다. 와 None도 출력된다.


[사용자에 나이를 입력받고 입장가능여부 알려주고 그날의 압장료 총 합 구하기]
```python
def get_total_fee():

  total_fee = 0

  while True: 
    ageer = (input("나이를 입력해주세요 : "))
    if ageer == "끝":
      break 

    age = int(ageer)

    if age < 8:
      print("8세 미만이시므로 무료입장가능하십니다.")
    elif age <= 19:
      print("5,000원으로 입장가능하십니다.")
      total_fee += 5000
    else:
      print("성인이시므로 10,000원입니다.")
      total_fee += 10000

  return total_fee
print(f"총 입장료 합계 : {get_total_fee()}원")
```
- 여기서 for문이 아닌 while문을 쓰는 이유는 몇번 반복할지 일단 정해놓지않았으니깐 while문을 사용한다. while문 뒤에는 참인지 거짓인지 판별할수 있는 조건식이 있으면 되는데 이렇게 True를 해놓으면 조건뭔지 모르겠고 내가 중간에 break로 멈출때까지 무한정 돌리겠다는거임 편하게 많이쓰는 방법이다.

```python
def vendin_machine():

  while True:
    menu = input("메뉴를 선택하세요 : ")

    if menu == "콜라":
      stock -= 1
      print(f"콜라 1개 나왔습니다! 남은 재고 : {stock}개")
    elif menu == "그만":
      break
    if stock == 0:
      print("재고가 모두 다 팔렸습니다.")
      break

vendin_machine()
```
